# Café de Santi

Proyecto de e-commerce de café y accesorios, desarrollado para la diplomatura de Coderhouse.

## Preentrega 1

Esta etapa incluye la estructura inicial del proyecto, la limpieza de la plantilla de Vite y una página de bienvenida.

Las funcionalidades de productos y carrito se incorporarán en las próximas entregas.

## Tecnologías

- React
- JavaScript
- Vite
- HTML y CSS
- Git y GitHub

## Instalación y ejecución

Se necesita tener Node.js y npm instalados.

1. Clonar el repositorio:

```bash
git clone https://github.com/santimachuca/mi-primer-proyecto-react.git
```

2. Entrar a la carpeta:

```bash
cd mi-primer-proyecto-react
```

3. Instalar las dependencias:

```bash
npm install
```

4. Iniciar el servidor:

```bash
npm run dev
```

5. Abrir en el navegador la dirección que indique la terminal.
